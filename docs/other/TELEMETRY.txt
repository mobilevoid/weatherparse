WEATHERPARSE TELEMETRY
======================

WeatherParse sends no telemetry.

Update Check
============

The optional update check (Admin, Settings, Site tab, "Check for Updates") asks GitHub at most once a day which
WeatherParse release is the latest:

    GET https://api.github.com/repos/mobilevoid/weatherparse/releases/latest
    User-Agent: WeatherParse

Nothing about your installation is sent: no install ID, no hardware or OS details, no MAC address, no version number.
GitHub sees only the request itself, like any website you visit. When a newer release exists, the admin dashboard shows
a notice. Turn the check off in the same place.

What Changed from Acuparse
==========================

Acuparse 3.x sent a daily "update check" to its own release server that included your operating system, kernel,
architecture, a unique install ID and your Access/smartHUB MAC address. That code has been removed from WeatherParse.

No Analytics
============

WeatherParse 4.1.1 removed the Google Analytics and Matomo options that Acuparse had. The pages load no tracking
scripts, and the updater deletes any old analytics settings from config.php.
