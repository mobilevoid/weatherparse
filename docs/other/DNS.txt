WEATHERPARSE DNS REDIRECT GUIDE
===============================

Your Access/smartHUB sends its readings to an AcuRite hostname (atlasapi.myacurite.com for the Access). To have them
arrive at WeatherParse instead, that hostname must point at your WeatherParse server.

Note:
    Access users can instead (or as well) change the Access upload server with the tool at /admin/access once logged
    into your site. You must use a hostname for the upload server; IP addresses will not work.

Note:
    Current Access firmware ignores the DNS server handed out by DHCP and asks 8.8.4.4 directly. A DNS override only
    works if those queries also reach your DNS server, for example by redirecting the Access's DNS traffic on your
    router or firewall, or with the iptables rules in the Raspberry Pi direct connect setup. See docs/TROUBLESHOOTING.txt,
    section "Hardcoded DNS Servers".

External Connection to WeatherParse
===================================

If your Access/smartHUB is on your local network, create a local DNS override for atlasapi.myacurite.com pointing at
your WeatherParse server.

DNS Servers
-----------

- Pi-hole (https://pi-hole.net), with a local DNS record.
- Bind9, Unbound, dnsmasq or similar on a device on your network.

Firewalls
---------

A firewall that lets you customise DNS (and redirect stray DNS traffic), such as:

- pfSense (https://www.pfsense.org/)
- OPNsense (https://opnsense.org/)

Direct Connection to WeatherParse
=================================

You can connect the Access directly to an Ethernet port on the WeatherParse server and let the server answer its DNS.
See docs/other/RPI_DIRECT_CONNECT.txt.

MyAcuRite Uploads
-----------------

With a local redirect, the WeatherParse server itself would resolve atlasapi.myacurite.com to its own address.
WeatherParse avoids this: when it forwards a reading to MyAcuRite it looks the address up through DNS directly (not
/etc/hosts) and never forwards to an address that belongs to the server. No "secondary" upload URL is needed; the old
Acuparse relay (atlasapi.acuparse.com) is no longer used.
