WEATHERPARSE UPDATE GUIDE
=========================

Back Up First
=============

Before any update, back up the database, your config file and your camera settings:

    mysqldump --single-transaction weatherparse | gzip > ~/weatherparse-db-$(date +%F).sql.gz
    cp /opt/weatherparse/src/usr/config.php ~/config.php.$(date +%F)
    cp /opt/weatherparse/cam/config.env ~/cam-config.env.$(date +%F)

Use your own database name if it is not weatherparse (an install upgraded from Acuparse usually keeps acuparse).

Updating WeatherParse
=====================

- Pull the changes:

      cd /opt/weatherparse
      sudo git pull

- Open your WeatherParse website and sign in as an admin. If the version changed, the site sends you to the in-app
  updater (/admin/install/?update). Click Begin Update and check your settings afterwards.

- 4.0.0 to 4.1.0 adds low battery email alerts. The updater adds their settings (on when Mailgun or a local mail
  program is set up; recipients empty = all admins; reminders every 24 hours; battery OK email on) and creates the
  battery_alert table. Review them in Admin, Settings, Features, Battery Alerts.

Upgrading from Acuparse 3.9.4
=============================

WeatherParse 4.0.0 is the continuation of Acuparse 3.9.4. Your database and settings carry over.

- Back up as above (the config file is /opt/acuparse/src/usr/config.php and the camera settings
  /opt/acuparse/cam/config.env).

- Get WeatherParse and copy your settings into it:

      sudo git clone https://github.com/mobilevoid/weatherparse.git /opt/weatherparse
      sudo cp -a /opt/acuparse/src/usr/config.php /opt/weatherparse/src/usr/
      sudo cp -a /opt/acuparse/cam/config.env /opt/weatherparse/cam/
      sudo chown -R www-data:www-data /opt/weatherparse/src/usr /opt/weatherparse/src/pub/img

  In cam/config.env change any /opt/acuparse paths to /opt/weatherparse. Keep the existing database name in
  config.php; no database rename is needed.

- Point Apache at /opt/weatherparse (use config/weatherparse.conf and config/weatherparse-ssl.conf, or change the
  DocumentRoot and Directory paths in your existing site files) and restart Apache.

- Change the cron entries from /opt/acuparse to /opt/weatherparse (see the Install Guide,
  https://github.com/mobilevoid/weatherparse/blob/main/docs/INSTALL.txt, section "Cron").

- Sign in as an admin and run the update to 4.0.0. It also moves MyAcuRite forwarding off the old acuparse.com relay
  to atlasapi.myacurite.com directly.

- Once everything works, keep /opt/acuparse as a fallback for a while before removing it.

Operating System Upgrades
=========================

When moving to a new Debian release, watch for:

- PHP: Debian 12 ships PHP 8.2 and Debian 13 PHP 8.4. Install the matching libapache2-mod-php, php-mysql, php-curl,
  php-gd and php-cli packages and make sure the old PHP Apache module is disabled and the new one enabled
  (a2dismod / a2enmod).
- OpenSSL 3: keep the Access TLS settings described in the Install Guide, section "Access TLS (OpenSSL 3)".
- Network interface names: Debian 12 and later name the Raspberry Pi onboard Ethernet end0 instead of eth0. Update
  dnsmasq, firewall rules and network settings that name the port.
- Timezone: Debian 13 moved old names such as US/Central to tzdata-legacy; set a current name such as
  America/Chicago with timedatectl set-timezone.
- After a MariaDB upgrade or an unclean shutdown, check the tables: mariadb-check --auto-repair --check <database>

Docker Install
==============

WeatherParse does not publish Docker images yet. Build the image locally from the Dockerfile; see the Docker Guide
(https://github.com/mobilevoid/weatherparse/blob/main/docs/DOCKER.txt).
